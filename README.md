# PROJETO-DE-FIM-DE-CURSO-OTIMIZA-O-DE-DRONES
Esse repositório contem meu trabalho de PFC 2 que consiste em um simulador, O FireDrone é um simulador que integra a propagação de incêndios florestais, a operação de drones e a otimização de frotas e táticas de combate, considerando critérios de contenção e custos operacionais.
