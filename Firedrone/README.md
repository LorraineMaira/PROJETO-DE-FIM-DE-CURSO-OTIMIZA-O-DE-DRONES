# FireDrone: simulador e otimizador de combate a incêndios com enxame de drones

    core/        motor único em JavaScript (dados, propagação do fogo, combate, otimização, Monte Carlo)
    frontend/    interface (index.html pronto; src/ e build.py para reconstruir)
    backend/     API HTTP em Python (sem dependências) que executa o mesmo motor via Node
    tests/       regressão, API, paridade navegador × Node, convergência de malha, lote dos 13 cenários

Comece por `COMO_USAR.md`.
